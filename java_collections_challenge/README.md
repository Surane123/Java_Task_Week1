# Java Collections Challenge

An interactive Java console program demonstrating practical uses of `ArrayList`, `HashMap`, and a first-in, first-out `Queue`.

## Features

- Add, remove, update, search, and display tasks in an `ArrayList`.
- Insert or update student IDs and names, retrieve values, check keys, and list entries with a `HashMap`.
- Add customers to a service line, serve the next customer, peek at the front, and display the line using a `Queue`.
- Validate menu choices and handle empty collections.

## Compile and run

Requires JDK 17 or newer. From this directory, run:

```powershell
javac -d out src\collections\*.java
java -cp out collections.Main
```

No external libraries are required.
