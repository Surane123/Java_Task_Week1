# Java Week 1 Assignment

This repository contains three related projects:

1. **Banking Application** — a Java console program for deposits, withdrawals, balance checks, and input validation. See [banking_application/README.md](banking_application/README.md).
2. **Java Collections Challenge** — an interactive demonstration of `ArrayList`, `HashMap`, and `Queue`. See [java_collections_challenge/README.md](java_collections_challenge/README.md).
3. **Library Management System** — a Java Servlet/JDBC web application with book and author operations. See [library_management_system/README.md](library_management_system/README.md).

Banking application Eclipse console screenshots are in [screenshots/banking_application](screenshots/banking_application/).

For a first-time setup, review the requirements in each project README. The library web application needs a servlet container and a database configured before its servlet actions can run.
